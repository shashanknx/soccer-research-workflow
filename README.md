# Soccer Research Workflow

This repository contains the initial setup and implementation scripts for the Soccer Research Workflow project.

## Project Structure
- `evidence_item.py`: Contains the Pydantic schema for EvidenceItem.
- `fetching.py`: Code for fetching data.
- `tagging.py`: Code for tagging data.
- `synthesizing.py`: Code for synthesizing data.
- `generating_reports.py`: Code for generating reports.

## Usage
Please follow the instructions to set up and run the project.
